# Мегосубнатика 2D — мобильная версия, планета 4546B

Полный исходный игровой код (Pygame) с экранными элементами управления для телефона.
Графика, функции генерации существ, карта, крафт, животные, подводные аппараты и
исходные механики сохранены; HTML формируется **pygbag** при публикации.

## Управление на телефоне

- **Левый нижний угол** — аналоговый джойстик движения; работает и при управлении подлодкой.
- **Касание свободной области мира** — прицелиться и выстрелить из экипированного
  оружия или торпедой из подлодки. Можно двигаться одним пальцем и стрелять другим,
  если браузер передаёт несколько FINGER-событий.
- **Кнопки справа**: УПОТР. (U, использовать/съесть), ЭКИП. (Q), ТРАНСП. (F),
  ПОДНЯТЬ (E), УДАР (пробел), СКАН (сканер либо посадка растений),
  СТРОИТЬ (B), ПЕЩЕРА (C), ЕЩЁ (дополнительные команды).
- В меню **ЕЩЁ**: фары, разрушение постройки, переход в главное меню, масштаб и панели.
- **Верхняя строка**: Рюкзак (R), крафт (I), карта (M), питомцы (T), настройки (N),
  увеличение (+) и уменьшение (−) масштаба.
- В рюкзаке коснитесь ячейки, затем кнопки УПОТР., ЭКИП., ТРАНСП., ВЫБРОС или
  ПИТОМЕЦ. Действия доступны без физических клавиш.
- В крафте/списке питомцев/посадках **коснитесь строки 1–9**, кнопки стрелок
  перелистывают страницы; в крафте «СТАНЦИЯ» переключает станцию, у питомцев
  можно забирать и лечить выбранного питомца.
- На карте **джойстик перемещает карту**, +/− меняют её масштаб.
- **НАЗАД/ЗАКРЫТЬ** — закрывает открытую панель; в игровом мире через «ЕЩЁ» → «МЕНЮ»
  можно вернуться на заставку.

На компьютере оставлено управление с клавиатуры и мыши. Клавиша **F9** на компьютере
включает/отключает отображение сенсорного управления для проверки.

## Публикация на GitHub Pages

1. Распакуйте архив в корень репозитория GitHub (включая скрытый каталог `.github`).
2. Убедитесь, что на GitHub присутствует `.github/workflows/pages.yml`.
3. В **Settings → Pages** задайте Source: **GitHub Actions**.
4. В **Actions** дождитесь выполнения `Build and deploy Megosubnatica2D to GitHub Pages`.
5. После сборки GitHub опубликует сайт по адресу:
   `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

Во время сборки `pygbag` создаёт **index.html** и WebAssembly-ресурсы; скрипт
`tools/patch_mobile_html.py` автоматически добавляет viewport и настройки
сенсорного ввода, чтобы страница не прокручивалась при использовании джойстика.
**Сам по себе файл Python не является HTML** — нельзя загрузить только `.py`
в GitHub Pages и ожидать запуска.

Если предыдущая версия проекта уже размещена, замените `game/main.py` и обновите
workflow; добавьте папку `tools/` и этот README.

### Проверка на компьютере

```bash
python -m pip install pygame-ce
python game/main.py
```

### Локальная браузерная сборка

```bash
python -m pip install pygbag==0.9.3
python -m pygbag --build --ume_block 0 game
python tools/patch_mobile_html.py game/build/web/index.html
```

После `--build` получите `game/build/web/index.html`. Для локального запуска
в браузере вместо `--build` используйте `python -m pygbag --ume_block 0 game`
и откройте выданный локальный адрес (обычно http://127.0.0.1:8000/).
Для кириллицы в браузерной сборке в каталоге `game/` нужен NotoSans.ttf,
который workflow скачивает автоматически.

## Совместимость и производительность

Игра строит большой мир и использует много детализированных Pygame-спрайтов.
На старых телефонах могут быть длительная генерация, низкая частота кадров
или нехватка памяти. Интерфейс адаптирован для касаний, но реальные
Android/iPhone/браузеры **здесь не тестировались**. Для удобства рекомендуется
Chrome на Android или Safari/Chrome на актуальной iOS. В некоторых браузерах
резервная эмуляция мышью может ограничивать одновременный джойстик и выстрел.

Планета называется **4546B**, старое название планеты не используется.
